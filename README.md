# HALODEK – React Native UI Challenge

##  Project Overview

HALODEK is a mobile chat application UI developed as part of the React Native Task 1 – UI Challenge.

The project focuses on recreating a selected mobile UI design using React Native, with attention to visual accuracy, component reusability, styling and responsive layouts.

##  Objective

To demonstrate an understanding of React Native components, styling with StyleSheet, reusable component architecture and responsive UI development.

##  Features

- Clean and modern chat interface.
- Chat, Status and Calls tab navigation design.
- Custom colour scheme inspired by the selected reference design.
- Contact list with profile avatars.
- Message previews and timestamps.
- Online typing indicator.
- Unread message badges.
- Message read receipts.
- Floating action button.
- Responsive mobile layout.

##  Technologies Used

- React Native
- TypeScript
- Expo
- React Native StyleSheet
- React Native Components

##  Design

The UI was inspired by a selected design from the provided UI Designs collection.

The implementation focuses on maintaining the original design's layout, colours, typography, spacing and overall appearance while using reusable React Native components.

##  Getting Started

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate into the project:

```bash
cd HallodekApp
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npx expo start
```

Scan the QR code using Expo Go to preview the application.
